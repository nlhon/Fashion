# Atelier AI ✦

A modern, original landing-page website for a **Fashion AI** platform — built to help
designers, brands, and emerging creatives advance their craft with artificial intelligence.

> Built as an original design inspired by contemporary AI product landing pages
> (the requested sample site could not be accessed, so this is a fresh, copyright-safe creation).

## What's inside

A fully responsive, single-page static site with:

- **Hero** — bold value proposition with animated gradient orbs and key stats
- **Platform features** — AI design generation, trend forecasting, moodboards, virtual try-on, tech packs, print lab
- **Interactive Studio demo** — type a prompt + pick an aesthetic to generate a live AI-style concept brief (runs entirely in the browser)
- **How it works** — a clear four-step creative journey
- **Gallery** — community concept showcase
- **Testimonials, pricing, and a sign-up CTA**
- Smooth scroll, scroll-reveal animations, mobile nav, and reduced-motion support

## Tech

Plain **HTML, CSS, and vanilla JavaScript** — no build step, no dependencies.
Fonts from Google Fonts (Fraunces + Inter).

## Run it

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page structure & content |
| `styles.css` | Design system, layout, responsive rules |
| `script.js`  | Nav, scroll reveals, gallery, and the interactive concept generator |
